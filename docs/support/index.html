Support

Help with recording, speech recognition, subscriptions, data, or privacy.

Before requesting help

  • Confirm microphone and speech-recognition access in iOS Settings.
  • Check your network connection when AI processing is unavailable.
  • Use Restore Purchases in Attune Settings for an existing subscription.
  • Include your Attune version and iOS version when reporting a problem.

Contact

Open a request in the Attune GitHub issue tracker. Do not post recordings, transcripts, account information, or other sensitive information in a public issue. A private support email will be added here before App Store submission.

Release requirement: this draft support page must be updated with a private contact email before it is used for App Store submission.
